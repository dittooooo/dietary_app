# Companion Agent 飲食營養測試問題與回應記錄

本文件用於記錄 companion agent 對 20 個真實使用者情境（單一餐點建議、餐點比較/搭配、飲食紀錄、邊界防呆）的回應結果。

---

## 📋 20 個測試問題快速複製區

您可以直接複製以下問題，由前端逐一傳送給 Companion Agent 進行測試：

```text
1. 我今天晚餐想吃一碗紅燒牛肉麵，請問這樣會不會太油或熱量太高？
2. 我剛買了一份豬肉蛋餅當午餐，這樣吃營養夠嗎？
3. 我想喝一杯珍珠鮮奶茶，如果點三分糖會不會比較沒負擔？
4. 我中午點了炸雞腿便當，如果我不吃皮的話熱量還會很大嗎？
5. 晚上肚子有點餓，想吃一碗鹹豆漿加蛋，適合當宵夜嗎？
6. 下午茶時間同事請吃一塊巴斯克乳酪蛋糕，這款適合減脂期吃嗎？
7. 我剛做完重訓，吃一盒超商的舒肥雞胸肉餐盒適合嗎？
8. 去滷味攤不知道要點乾意麵還是切汁米血跟豆干，這兩個哪一個熱量比較低？
9. 午餐想吃便當，主食選烤雞腿便當跟滷排骨便當，哪一個比較推薦？
10. 喝手搖飲加波霸珍珠跟加寒天蒟蒻，熱量跟糖分差很多嗎？
11. 我中午吃了麥當勞的大麥克套餐，那晚餐吃鹽水雞搭配蔬菜是不是比較合適？
12. 下午喝了一碗紅豆湯，晚上如果吃麻辣鍋會不會熱量過爆？
13. 去夜市吃晚餐，選擇小籠包配酸辣湯，還是牛肉湯麵比較不會攝取過多油脂？
14. 早上已經吃過起司蛋吐司配大冰奶，晚餐如果吃火鍋要點什麼肉比較好？
15. 幫我記錄一下，我今天早上吃了一顆茶葉蛋和一杯無糖高纖豆漿。
16. 我剛才午餐吃了牛肉麵一碗，還喝了一杯無糖綠茶。
17. 幫我記一下飲食，我上午吃了一份鮪魚蛋吐司，中午吃了一盒舒肥雞胸肉沙拉。
18. 剛剛下午茶時間吃了一包堅果跟半顆蘋果，請幫我記上去。
19. 今天晚餐吃了清蒸魚一份、燙青菜一盤跟半碗玄米飯，記錄一下。
20. 今天台北天氣好冷喔，你覺得我下午應該去哪裡散步比較好？
```

  > 
- **評價與優缺點分析**：
